# Fonts

Bundled so the page needs no font host (the policy allows `font-src 'self'` only). Latin subset, woff2, from Google Fonts on 2026-11-14.

| File                    | Family    | Axes                           | Licence                   |
| ----------------------- | --------- | ------------------------------ | ------------------------- |
| `archivo-latin.woff2`   | Archivo   | weight 800 to 900, width 125 % | SIL Open Font License 1.1 |
| `work-sans-latin.woff2` | Work Sans | weight 400 to 600              | SIL Open Font License 1.1 |

Archivo is used for display text and headings (uppercase, wide). Work Sans is the body font.
